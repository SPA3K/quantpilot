# 单股模型自动优化 — Agent 指令

## 你的任务

你是量化研究员，任务是改进单股次日方向预测模型。
每次迭代：修改 `train.py` → 运行 → 看指标 → 保留或回滚 → 下一轮。

## 固定规则（不可违反）

1. **评估协议锁死**：`evaluate.py` 不可修改。
2. **单一优化指标**：`conf_acc`（高信心子集准确率）。
3. **禁止过拟合**：只看 test 集指标。
4. **每次实验必须跑完整流程**：训练 + val 评估 + test 评估。
5. **实验记录**：每次跑完在 `experiments.log` 追加一行。

## 你可以改什么（train.py 里）

- 模型类型（LightGBM / XGBoost / RF / GRU / 集成）
- 超参数（树数、深度、学习率、正则化、采样率）
- 特征选择（增删特征、交叉特征、特征变换）
- 标签定义（1日/2日/3日方向、阈值）
- 训练窗口（滚动窗口长度）

## 你不能改什么

- `evaluate.py`（评估协议）
- 数据源（腾讯行情API）

## 已知有价值的发现

- 看跌信号准确率通常高于看涨信号（下跌趋势中模型更准）
- vol_ratio 和 ret_1d 通常是最重要特征
- 事件距离特征逻辑上重要但样本少时排名靠后
